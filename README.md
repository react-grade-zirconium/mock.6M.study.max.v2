# 고1 6월 모의고사 6과목 훈련 앱

고1 6월 전국연합학력평가 흐름에 맞춰 6과목을 한 과목씩 풀 수 있는 정적 웹앱입니다. 짧은 단문형 문제만 반복되지 않도록, 실제 시험지처럼 **긴 지문·자료 하나에 여러 문항이 붙는 세트형 구성**을 강화했습니다.

## 구성

| 과목 | 문항 수 | 제한 시간 | 지문·자료 세트 | 범위 |
| --- | ---: | ---: | ---: | --- |
| 국어 | 45 | 80분 | 15세트 | 독서·문학·화법과 작문·언어 |
| 수학 | 30 | 100분 | 10세트 | 다항식·방정식·부등식·함수 |
| 영어 | 45 | 70분 | 15세트 | 듣기형 상황·장문 독해·어법·빈칸 |
| 한국사 | 20 | 30분 | 5세트 | 선사~근현대 흐름·자료 해석 |
| 통합사회 | 20 | 30분 | 5세트 | 인권·시장·환경·문화·공간 |
| 통합과학 | 20 | 30분 | 5세트 | 물질·생명·지구·에너지 자료 해석 |

## 특징

- 전년도 기출을 그대로 복제하지 않고 소재, 조건, 수치, 선지를 바꾼 원문항으로 구성했습니다.
- 국어·영어는 지문 1개당 3문항, 한국사·통합사회·통합과학은 자료 1개당 4문항이 이어지는 방식으로 바꾸었습니다.
- 수학도 공통 조건을 먼저 읽고 값 계산, 교점 추론, 문장제 식 세우기를 연속해서 풀도록 구성했습니다.
- 과목별 문항 수와 시간은 고1 6월 모의고사 실전 연습에 맞춰 유지했습니다.
- 시작/일시정지/채점 기능과 시간 종료 시 자동 채점을 제공합니다.
