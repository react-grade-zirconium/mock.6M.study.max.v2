# 고1 6월 모의고사 6과목 훈련 앱

고1 6월 전국연합학력평가 흐름에 맞춰 6과목을 한 과목씩 풀 수 있는 정적 웹앱입니다.

## 구성

| 과목 | 문항 수 | 제한 시간 | 범위 |
| --- | ---: | ---: | --- |
| 국어 | 45 | 80분 | 비문학·문학·문법 |
| 수학 | 30 | 100분 | 다항식·방정식·함수 |
| 영어 | 45 | 70분 | 듣기형 상황·독해·어법 |
| 한국사 | 20 | 30분 | 선사~근현대 흐름 |
| 통합사회 | 20 | 30분 | 인권·시장·환경·문화 |
| 통합과학 | 20 | 30분 | 물질·생명·지구·에너지 |

## 특징

- 전년도 기출을 그대로 복제하지 않고 소재, 조건, 수치, 선지를 바꾼 원문항으로 구성했습니다.
- 과목별 문항 수와 시간은 고1 6월 모의고사 실전 연습에 맞춰 유지했습니다.
- 시작/일시정지/채점 기능과 시간 종료 시 자동 채점을 제공합니다.
